# TradeX - Crypto Trading Bot

TradeX is a full-stack crypto trading bot application built with React, Spring Boot and MongoDB.

## Project Structure

```text
TradeX/
├── frontend/
└── backend/
cd backend
mvnw.cmd spring-boot:run
cd frontend
npm install
Technologies Used
Frontend
React
Vite
JavaScript
CSS
Backend
Java
Spring Boot
Spring Data MongoDB
Maven
Database
MongoDB
Requirements

Before running the project, install:

Git
Node.js
Java JDK
MongoDB
MongoDB Setup

TradeX uses a local MongoDB database.

MongoDB connection:

mongodb://localhost:27017/test

Database:

test

The application uses these collections:

users
trading_bots
bots

Make sure MongoDB is running before starting the backend.

Backend Setup

Open a terminal and go to the backend folder:

cd backend

On Windows, run:

mvnw.cmd spring-boot:run

The backend runs on:

http://localhost:8182
Frontend Setup

Open another terminal and go to the frontend folder:

cd frontend

Install dependencies:

npm install

Start the React development server:

npm run dev

The frontend will show the local URL provided by Vite.

API

The frontend communicates with the Spring Boot backend.

Login API:

http://localhost:8182/api/users/login

Trading Bot API:

http://localhost:8182/api/trading-bots
Running the Complete Project
Step 1

Start MongoDB.

Step 2

Start the backend:

cd backend
mvnw.cmd spring-boot:run
Step 3

Open another terminal and start the frontend:

cd frontend
npm install
npm run dev
Step 4

Open the frontend URL shown by Vite in your browser.

Important

This project uses local MongoDB.

The MongoDB database itself is not included in this GitHub repository.

Each user must have MongoDB installed and running on their own machine.

License

This project is for educational and development purposes.
EOF~
